# Revisión de calidad de interfaz

Revisa la implementación REAL (código y, si es posible, la app corriendo), no el diseño planeado.

Checklist: calidad visual y consistencia con `VISUAL_DIRECTION.md` · flujos y estados (incluye error/empty/loading) · accesibilidad · responsive · patrones genéricos · evidencia (archivo:línea o captura).

Cada hallazgo: qué · dónde · severidad (crítico/alto/medio/bajo) · tipo (bug real / riesgo / mala práctica / opcional) · mejora sugerida. Solo reporta; no edites.
